## Public Profile

Run the public profile smoke test and manifest-selected module package build:

```bash
mvn -Ppublic -pl core/ouroboros-data -am test
mvn -Ppublic -pl core/ouroboros-data/ouroboros-data-core,core/ouroboros-data/ouroboros-data-plugins,core/ouroboros-data/ouroboros-data-typed-core,core/ouroboros-data/ouroboros-data-typed-meta-processor,core/ouroboros-data/ouroboros-data-sql,core/ouroboros-data/ouroboros-data-sql-migration,core/ouroboros-data/ouroboros-data-builders,core/ouroboros-data/ouroboros-data-test-support,core/ouroboros-data/ouroboros-data-pkgen-coding -am -DskipTests package
```

## Contribution Policy

External contributions are accepted with DCO sign-off. CLA is not required for
the public export fixture generated by this workflow.

## Primary Key Boundary

`data-pkgen-coding` is part of the first public profile. It uses the
`DataExpressionEvaluator` port from `ouroboros-data-core`; concrete expression
engines, DB-backed sequence behavior, script wrappers and snowflake runtime
adapters remain external adapter concerns.
